# UCC 支援護理人力預班 自動登記工具

照系統流程 **點日期 → 點右邊的班（院區／診1・診2・備援／白・夜）→ 輸入帳號密碼送出**，
在開放時間（對齊國家標準時間）一到就以最快速度把願望清單填完。

## 安裝與啟動

需要 Python 3.9 以上（Windows 從 python.org 安裝，勾選 *Add to PATH*）。

- **Windows**：雙擊 `start.bat`（第一次會自動安裝套件）
- **Mac**：雙擊 `start.command`
- 手動：`pip install -r requirements.txt`、`python -m playwright install chromium`、`python ucc_gui.py`

## 使用步驟

1. **① 點日期**（可多選，有全選／週末／平日快捷）
2. **② 選班**：勾院區、白班／夜班，選診別順序（預設 **診1→診2→備援**）→ 按 **➕ 加入清單**
   - 同一天可以加很多筆（例如 12/19 林森白、林森夜、昆明白…）
   - 清單可上移／下移／刪除；同一天依清單順序執行
3. **④ 開放時間**：例如 `2026-12-14 09:00:00`；大時鐘是校時後的國家標準時間
4. 按 **⏰ 開始排程** → 跳出視窗輸入 **ID / 密碼**
   - 可勾「顯示密碼」檢查，下方會顯示 `ID：[...]` `密碼：[...]（N 個字）`，有多打空白會警告
   - **只在這次執行有效，不會存檔**；保存的原始碼中密碼會被遮蔽
5. 時間一到：
   - **日期由後往前**選（避開大家都從月初搶的格子）
   - 每一筆：點日期 → 點班；**診1 額滿或送出時被搶，立刻改診2，再沒有才備援**
   - 系統要求帳密時自動填入並確認
   - 若尚未開放，會持續重新整理重試（預設 90 秒）
6. 清單的「結果」欄會顯示每筆 ✓ 成功 / ✗ 額滿 / ? 未確認

模擬測試（伺服器延遲 0.4 秒）：**5 班 4.4 秒完成**。實際速度取決於醫院系統回應速度。

> 排程期間保持電腦開機、不要睡眠。只登記你自己的班。

## 保存原始碼（讓下次寫出更快的程式）

- 每次執行都會在 `captures/日期時間/` 保存：每個步驟的網頁 HTML、截圖、`network.jsonl`（所有請求與回應，含 Google Apps Script 的原始 HTML 與 `google.script.run` 呼叫）
- 也可以按 **🔍 手動操作並錄下原始碼**：開啟網頁讓你自己點一輪，程式在旁邊每 5 秒錄一次
- 把 `captures/` 資料夾提供給開發者，就能直接呼叫系統的 API，跳過畫面操作，速度可以再快很多

## 進階設定

| 項目 | 說明 |
|---|---|
| 提前開網頁 | 預設 20 秒前開好網頁 |
| 提早開始(毫秒) | 0＝準時；可設 100～300 補償網路延遲 |
| 未開放持續重試 | 預設 90 秒 |

`python ucc_booking.py --pause`：只輸出網頁結構到 `inspect_report.txt`（除錯用）。
