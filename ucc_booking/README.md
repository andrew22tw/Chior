# UCC 支援護理人力預班 自動登記工具

依 **實際系統原始碼** 設計（Google Apps Script「UCC 週日及國定假日排班系統」）。

## 系統實際規則（2026-11-08 從系統讀取）

| 項目 | 實際 |
|---|---|
| 開放 | 每月 **14 日 09:00–11:00**，預約下個月 |
| 院區 / 班別 | 林森、昆明、廣慈 / 白班 8AM-4PM、夜班 4PM-12AM |
| 可排日期 | 週日與國定假日 |
| 診別 | 診1、診2、備援（備援要等診1、診2 都被約走才開放） |
| **每人每天只能 1 班** | 同一天在清單放多筆 = 備選順序 |
| 預約方式 | 一次伺服器呼叫 `createBooking(日期, 院區, 班別, 診別, 員編, 密碼)` |
| 伺服器速度 | 讀取全部資料 3.5–5 秒；預約一次預估 1–3 秒（尖峰可能更慢） |

網頁畫面上的「未開放預約」是用 **你電腦的時鐘** 判斷，且要重新點日期才會更新；預約成功後畫面會重新下載全部資料（約 4 秒）。
所以本工具 **不點畫面**，而是在網頁裡直接呼叫 `createBooking`：

- 標準時間一到（**不會提早**）**所有日期同時送出**
- 同一天：清單順序 × 診別順序（預設 **診1 → 診2 → 備援**；個別可改 診2 先）
- 被搶走就立刻送下一個候選；伺服器回「尚未開放」就每 0.3 秒重試
- 完成後向系統查詢你名下的預約，列出確認

模擬（伺服器每次 1.5 秒、其中兩天診1 已被搶）：**3 天 3 個班 3.0 秒完成**。

## 安裝與啟動

- **Windows**：雙擊 `start.bat`　**Mac**：雙擊 `start.command`
- 手動：`pip install -r requirements.txt`、`python -m playwright install chromium`、`python ucc_gui.py`

## 使用步驟

1. 月曆點日期 → 勾院區、白班/夜班 → **➕ 加入清單**（清單只有 日期／院區／白夜）
2. 要某一列「診2 先」：選取該列按 **⇄ 診2先**
3. 開放時間填 `2026-11-14 09:00:00`（12 月的班），按 **⏰ 開始排程**
4. 跳出視窗輸入 ID / 密碼（可勾「顯示密碼」檢查；**只在本次有效，不存檔**）
5. 開放前 40 秒自動開網頁、等系統載入；09:00:00 準時同時送出

## 雲端／無介面執行

GUI 按 **匯出雲端** 產生 `wishes.json`（不含帳密），然後：

```bash
UCC_ID=員編 UCC_PW=密碼 python ucc_run.py wishes.json
```

未設定環境變數會詢問。`--now` 立即送出（開放時間內用）。開放時間一律以台灣時間計算。

## 其他

- `captures/`：每次執行保存網頁原始碼、截圖、網路紀錄（密碼遮蔽）
- `python ucc_booking.py --pause`：輸出網頁結構（除錯用）
- 只登記你自己的班。
